SHINRI TRACKER v0.9
==================

1) Распакуй содержимое этого архива В КОРЕНЬ существующего проекта.
   gui.py, match_monitor.py, database_utils.py, player.py и players_list.py
   нужно заменить версиями из архива.

2) Для запуска из PyCharm один раз запусти install_dependencies.bat.

3) Общие группы Google Drive начнут работать после одноразовой настройки
   google_credentials.json. Подробно: SETUP_GITHUB_GOOGLE.txt.

4) Автообновление привязывается к GitHub Releases. Готовый workflow уже лежит в:
   .github/workflows/release.yml

5) Текущая версия исходников: 0.9.0.


ВАЖНО ДЛЯ ОБЩИХ ГРУПП (v9.1):
После того как владелец пригласил новый Google-аккаунт и передал ему .shinrigroup,
при первом подключении Google может открыть окно выбора файла Drive. Это нормально:
drive.file намеренно требует, чтобы каждый участник один раз явно разрешил приложению
доступ к database.json. Выбери предложенный файл и подтверди. Повторять это при каждой
синхронизации не нужно.
